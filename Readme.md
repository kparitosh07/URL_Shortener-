# 🔗 URL Shortener

A scalable URL Shortener built using **Node.js, Express.js, MongoDB, HTML, CSS, and JavaScript**.

The application converts long URLs into short, shareable links and tracks basic click analytics.

## 🚀 Features

- Shorten long URLs
- Generate unique short codes
- Custom URL aliases
- Custom alias collision handling
- Optional URL expiration
- Automatic click counting
- Last accessed timestamp
- HTTP 302 redirection
- URL validation
- REST APIs
- Responsive frontend
- MongoDB data persistence

## 🛠️ Tech Stack

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- NanoID
